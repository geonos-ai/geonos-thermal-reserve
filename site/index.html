Proposed field workflow

How a site would prepare and review a peak-load plan.

In a field pilot, GEONOS would use records the site already has. The operator would set the limits, review the plan and stay in control.

  1. 01

    Read the site

    Start with existing records.

    A pilot would begin with interval power, storage temperature, compressor and defrost status, door activity, schedules and local weather.

    Missing data would be flagged rather than guessed.
  2. 02

    Set the limits

    Define what the plan cannot cross.

    The operator would set the temperature range, peak window, recovery rules and equipment constraints.

    A field plan that crossed a limit would be rejected.
  3. 03

    Test the day

    Compare a baseline with a shift.

    The prototype tests pre-cooling, a temporary load reduction and the rebound that follows.

    Outputs are estimates until a field test is completed.
  4. 04

    Check the event

    Measure before making a claim.

    A pilot would compare planned and actual load, temperature and rebound after an approved test.

    Uncertainty and exclusions would stay in the report.

Clear boundaries

The operator remains in charge.

The current prototype evaluates example scenarios. A field version would not bypass the site controller or replace qualified refrigeration judgment.

One site · 90 days

Test the workflow at one cold store.

The first pilot is deliberately small: understand one facility, prepare one operator-reviewed plan and measure one supervised test before discussing scale.

  1. Days 1–30

    Map and baseline

    Review power, temperature, operating and weather data. Agree on gaps, site limits and the baseline method. No equipment is changed.

  2. Days 31–60

    Model and review

    Test candidate peak windows with the operator and HVAC/R technician. Reject any plan that does not meet the site's rules.

  3. Days 61–90

    Test and report

    If the site approves, run one small, manually supervised event. Report the measured result—or explain why the right answer was no-go.

What the pilot delivers

  • A documented baseline and data-gap review
  • One operator-approved peak-load plan
  • A measured result with uncertainty, or a documented no-go
  • A decision on whether a larger trial is justified

How we judge it

  • Site-set temperature limits are maintained
  • Delivered reduction is compared with the plan
  • Rebound size and timing are recorded
  • The operator can understand and repeat the workflow

About GEONOS

Peak-load planning for cold-storage operations.

Refrigeration load may have some flexibility. Food safety and site reliability come first. GEONOS is being built to help operators test that flexibility before they use it.

Why Antalya

Hotter conditions make careful planning more useful—and less forgiving.

In the public NASA POWER grid-cell record used for this demo, Antalya's 2016–2025 average temperature was 1.29°C above 1991–2000. Cooling degree days were 15.4% higher.
